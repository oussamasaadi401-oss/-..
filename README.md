# LUXORA — النسخة المصححة

تم الحفاظ على تصميم الواجهة الأصلي في `public/index.html`. تم إصلاح خطأ ربط الحفظ بالواجهة، واستعمال SQLite المدمجة داخل Node.js بدلاً من `better-sqlite3` حتى لا تحتاج إلى Python أو node-gyp أو تثبيت مكتبات خارجية.

## التشغيل على Windows / VS Code

1. فك ضغط ZIP وافتح مجلد `LUXORA-Fixed` في VS Code.
2. انسخ `.env.example` وسمّ النسخة `.env`.
3. افتح `.env` وغيّر `ADMIN_PASSWORD` إلى كلمة مرور خاصة لا تقل عن 12 حرفاً.
4. افتح Terminal في هذا المجلد ونفّذ:

   ```powershell
   npm.cmd start
   ```

   لا تحتاج إلى `npm install` لأن المشروع لا يعتمد على أي مكتبات خارجية.

5. اترك Terminal مفتوحاً وافتح Chrome على `http://127.0.0.1:3000`.

## اختبار السيرفر

افتح `http://127.0.0.1:3000/api/health` ويجب أن تظهر نتيجة JSON فيها `"ok":true`.

## الحفظ

- المنتجات والطلبات والاشتراكات محفوظة في ملف `luxora.sqlite`.
- السلة والمفضلة محفوظتان في `localStorage` في المتصفح.
- قاعدة البيانات والمنتجات التجريبية تُنشأ تلقائياً عند أول تشغيل.

## ملاحظة

هذه نسخة تطوير محلية وليست إعداداً جاهزاً لنشر متجر عام أو استقبال مدفوعات حقيقية. لا تشارك ملف `.env` أو كلمة مرور الإدارة.
